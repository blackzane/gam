## Projet Échecs – C++

### Objectif
Créer un jeu d’échecs graphique avec IA et règles complètes.

### Technologies
- C++17
- SDL3
- ImGui

### Fonctionnalités
- Jeu joueur vs IA
- Détection échec / échec et mat
- Interface graphique interactive

### Extensions possibles
- Réseau
- Sauvegarde
- IA plus avancée
